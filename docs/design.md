# 한지붕 MVP 설계 요약

로그인 없이 **초대코드 + 방장 승인**으로 가족이 함께 쓰는 가계부. 앱 전용(iOS·Android), 문자 자동입력은 출시 후.

## 역할과 권한

가계부마다 방장 1명, 부방장 0~3명, 나머지는 멤버. 모든 권한 검사는 서버에서 한다.

| 기능 | 방장 | 부방장 | 멤버 |
| --- | --- | --- | --- |
| 내역 작성·수정·삭제 | O | O | O |
| 카테고리 관리 | O | O | X |
| 가계부 이름 수정 | O | X | X |
| 초대코드 보기 | O | O | X |
| 초대코드 재발급 | O | X | X |
| 참여 요청 승인·거절 | O | O | X |
| 요청을 기존 멤버에 연결 | O | O (방장 연결 포함) | X |
| 멤버 차단 | O | O (멤버만) | X |
| 부방장 지정·해제 | O | X | X |
| 방장 양도 | O | X | X |
| 복구코드 재발급 | O | X | X |
| 가계부 삭제 | O | X | X |
| 나가기 | X (양도 또는 삭제) | O | O |

## 멤버 상태

`pending → approved`, `pending → rejected`, `approved → revoked | left`.
거절·차단·나감 이후 같은 초대코드로 재요청하면 **같은 행**이 `pending`으로 돌아가고, 차단 이력은 `was_revoked`로 남아
승인 목록에 "이전에 차단한 멤버"로 표시된다. 행을 지우지 않으므로 내역의 작성자가 유지된다.

## 기기 식별

- 최초 실행 시 앱이 랜덤 **설치 키**를 만들어 보안 저장소에 둔다 (iOS Keychain은 재설치 후에도 대체로 유지).
- 서버는 설치 키로 **기기 토큰**을 발급한다. 모든 멤버십은 기기 계정에 붙는다.
- 서버에는 설치 키·토큰·복구코드·이전 코드를 SHA-256 해시로만 저장한다. 초대코드만 평문.

## 기기 변경과 복구

| 상황 | 방장 | 부방장 | 멤버 |
| --- | --- | --- | --- |
| 같은 폰 재설치 | 설치 키로 자동 복구 | 〃 | 〃 |
| 폰 교체, 이전 폰 있음 | 기기 이전 코드 (10분, 1회용) | 〃 | 〃 |
| 폰 교체, 이전 폰 없음 | 복구코드 | 초대코드 재요청 → 방장·다른 부방장이 기존 멤버로 연결 | 초대코드 재요청 → 방장·부방장이 연결 |
| 방장이 이전 폰·복구코드 모두 없음 | 초대코드 재요청 → 부방장이 방장으로 연결 | — | — |

## 카테고리

종류는 **공통 / 지출 / 수입**. 공통은 지출·수입 어디서든 고를 수 있다. 기본 공통 카테고리 9개
(식비, 생활, 교통, 주거, 의료, 교육, 경조사, 급여, 기타). 라벨 색은 종류를 따른다: 공통 회색, 지출 주황, 수입 파랑.

## 출시 후

푸시 알림(요청·승인·차단), 자동입력(Android 알림 읽기, iOS 단축어), 통계·예산.
