# 한지붕 MVP 설계 요약

로그인 없이 **초대코드 + 방장 승인**으로 가족이 함께 쓰는 앱 시리즈. 앱 전용(iOS·Android).

- **한지붕 가계부**: 공간 = 가계부, 문자 자동입력은 출시 후
- **한지붕 메모**: 공간 = 메모집, 글 메모·체크리스트

아래 역할·멤버 상태·기기 식별·복구는 두 앱이 똑같다. 서버에서는 `ledgers` 테이블의 `kind`(budget / memo)로 나누고,
가계부 코드를 메모 앱에 넣거나 메모집 ID로 가계부 API를 부르면 "찾을 수 없음"으로 처리한다.

## 역할과 권한

가계부·메모집마다 방장 1명, 부방장 0~3명, 나머지는 멤버. 모든 권한 검사는 서버에서 한다. 아래 표의 "가계부"는 메모집도 같다.

| 기능 | 방장 | 부방장 | 멤버 |
| --- | --- | --- | --- |
| 내역 작성·수정·삭제 | O | O | O |
| 카테고리 관리 | O | O | X |
| 가계부 이름 수정 | O | X | X |
| 초대코드 보기 | O | O | X |
| 초대코드 재발급 | O | X | X |
| 참여 요청 승인·거절 | O | O | X |
| 요청을 기존 멤버에 연결 | O | O (방장 연결 포함) | X |
| 멤버 차단 | O | O (멤버만) | X |
| 부방장 지정·해제 | O | X | X |
| 방장 양도 | O | X | X |

## 멤버 상태

`pending → approved`, `pending → rejected`, `approved → revoked | left`.
거절·차단·나감 이후 같은 초대코드로 재요청하면 **같은 행**이 `pending`으로 돌아가고, 차단 이력은 `was_revoked`로 남아
승인 목록에 "이전에 차단한 멤버"로 표시된다. 행을 지우지 않으므로 내역의 작성자가 유지된다.

## 기기 식별

- 최초 실행 시 앱이 랜덤 **설치 키**를 만들어 보안 저장소에 둔다 (iOS Keychain은 재설치 후에도 대체로 유지).
- 서버는 설치 키로 **기기 토큰**을 발급한다. 모든 멤버십은 기기 계정에 붙는다.
- 서버에는 설치 키·토큰·복구코드·이전 코드를 SHA-256 해시로만 저장한다. 초대코드만 평문.

## 기기 변경과 복구

| 상황 | 방장 | 부방장 | 멤버 |
| --- | --- | --- | --- |
| 같은 폰 재설치 | 설치 키로 자동 복구 | 〃 | 〃 |
| 폰 교체, 이전 폰 있음 | 기기 이전 코드 (10분, 1회용) | 〃 | 〃 |
| 폰 교체, 이전 폰 없음 | 복구코드 | 초대코드 재요청 → 방장·다른 부방장이 기존 멤버로 연결 | 초대코드 재요청 → 방장·부방장이 연결 |
| 방장이 이전 폰·복구코드 모두 없음 | 초대코드 재요청 → 부방장이 방장으로 연결 | — | — |

## 카테고리

종류는 **공통 / 지출 / 수입**. 공통은 지출·수입 어디서든 고를 수 있다. 기본 공통 카테고리 9개
(식비, 생활, 교통, 주거, 의료, 교육, 경조사, 급여, 기타). 라벨 색은 종류를 따른다: 공통 회색, 지출 주황, 수입 파랑.

## 한지붕 메모

### 권한

| 기능 | 방장 | 부방장 | 멤버 |
| --- | --- | --- | --- |
| 메모 쓰기, 모든 메모 수정, 고정, 체크리스트 항목 추가·수정·체크·삭제 | O | O | O |
| 메모 삭제(휴지통)·되살리기 | O | O | 내가 쓴 메모만 |

휴지통은 30일 동안 보이고 그 뒤에는 목록에서 사라진다.

### 동시 수정

- 메모마다 `version`. 제목·본문을 저장할 때 **고치기 시작한 버전**(`base_version`)을 함께 보낸다.
- 그사이 아무도 안 고쳤으면 그대로 저장, 버전 +1.
- 누가 먼저 고쳤으면 서버가 원본(`base_version` 내용, `memo_revisions`에 최근 50개 보관)·내 글·지금 글을 줄 단위로 3방향 병합한다.
  서로 다른 줄(바로 옆 줄 포함)이면 합쳐서 저장하고 `merged: true`. 같은 줄을 서로 다르게 고쳤으면 409 + 지금 내용.
  제목은 통째로 비교한다. 바뀐 게 없으면 버전을 올리지 않는다(자동 저장이 같은 글을 다시 보내도 됨).
- 체크리스트 항목은 한 줄씩 따로 저장한다. 글자 수정만 항목 `version`을 비교하고, 체크는 마지막 요청이 이긴다.
- 메모를 연 동안 15초마다 "보고 있어요" 신호(30초 안에 신호를 보낸 사람만 표시).

### 오프라인

연결 여부는 실제 요청 성공·실패로 판단한다. 오프라인에서는 읽기(기기 캐시)만 되고 쓰기는 막는다.
예외 두 가지: 고치던 중 끊기면 초안으로 남겼다가 연결되면 저장(서버가 병합), 체크·해제는 모아 뒀다가 연결되면 전송.

## 출시 후

- 가계부: 푸시 알림(요청·승인·차단), 자동입력(Android 알림 읽기, iOS 단축어), 통계·예산
- 메모: 실시간 반영(WebSocket), 이미지 첨부, 푸시 알림, 가계부 멤버를 메모집에 바로 초대
